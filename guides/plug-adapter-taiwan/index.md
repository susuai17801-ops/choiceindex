# 電源轉接頭怎麼選？家鄉帶來的圓腳插頭轉台灣插座，先看電壓再看插頭

最後更新：2026年10月18日
選品索引 ChoiceIndex — https://choiceindex.tw/

台灣的家用插座是 110V、扁腳插頭；印尼、越南等國多半是 220V 左右，插頭也常是圓腳。把家鄉帶來的充電器、風扇或電器帶到台灣，第一件事常常是插頭插不進插座。蝦皮上賣的轉接頭很多，但大部分是「台灣插頭轉出國用」的旅行轉接頭，方向剛好相反。更重要的是：轉接頭只改插頭形狀，不會改電壓。這篇整理轉接頭的類型、五個挑選關鍵，以及一定要先看電器標示的原因，下單之前先對一次。

## 先搞懂：常見的四種轉接頭

| 類型 | 做什麼用 | 適合誰 | 要留意 |
|---|---|---|---|
| 歐規轉美規（圓腳轉扁腳） | 把圓腳插頭（常見於印尼等國）轉成台灣插座用的扁腳插頭，賣場常寫「韓國／越南／印尼／歐洲轉台灣使用」 | 從家鄉帶電器或充電器到台灣的人 | 只改形狀，不改電壓；下單前確認方向是「轉進台灣」，不是「台灣轉出國」 |
| 旅行轉接頭（台灣轉出國） | 把台灣的扁腳插頭轉成歐規、英規、澳規等，出國旅行用 | 台灣人出國旅遊 | 方向和上面相反，買錯在台灣插不進去；蝦皮上這類最多 |
| 萬用（多國）轉接頭 | 輸入孔可插多種插頭，輸出端可切換不同規格，有些款式可輸出扁腳 | 常在不同國家使用的人 | 要確認有「美規（台灣）」輸出；多功能構造較複雜，插拔多次後要留意是否鬆動 |
| 三孔轉兩孔 | 把有接地腳的三孔插頭轉成兩孔插座可用 | 家裡只有兩孔插座的人 | 不是轉換國家規格；接地腳被省略，使用上要留意安全 |

## 轉接頭要看的五個關鍵

| 關鍵 | 要看什麼 | 常見狀況 |
|---|---|---|
| 方向 | 確認是「轉進台灣用」（歐規轉美規／圓腳轉扁腳）還是「台灣轉出國用」。賣場常常把多個方向放在同一頁的不同規格，要選對 | 買到旅行用的轉接頭，帶來的圓腳插頭還是插不進台灣插座 |
| 電器電壓標示 | 看電器或充電器銘牌上的「輸入（INPUT）」。標示 100–240V（常見於手機、筆電的充電器）才可以只用轉接頭；只標 220V 或 230V 的電器，在台灣 110V 的插座可能不運轉或不正常運轉，不能靠轉接頭解決 | 只看插頭插得進去，沒看電壓，結果電器沒反應或表現異常 |
| 插頭形狀與腳徑 | 看自己電器的插頭是圓腳（兩根圓柱）還是扁腳，圓腳常見粗細不同（例如 4.0mm 與 4.8mm），腳徑不合會插得太鬆或太緊。有些國家的扁腳插頭（例如越南、菲律賓部分電器）也可能直接插台灣插座 | 圓腳粗細不合，插起來鬆鬆的接觸不良 |
| 額定功率與電流 | 看轉接頭有沒有標示可承受的功率與電流，且要大於電器的功率。賣場沒標示時，電熱水壺、電鍋、熨斗、吹風機等高功率電熱電器一律不要接 | 拿高功率電器接轉接頭，轉接頭過熱 |
| 使用安全與品質 | 選材質看起來紮實、插腳不鬆動的，賣場若沒有標示安規或認證，不能直接當成合格；使用中若發燙、有焦味或插頭鬆動就停用 | 買到太便宜的無標示商品，用久之後插腳鬆動、發熱 |

沒有哪一種轉接頭「最好」，要先看電器電壓標示，再看插頭形狀與使用功率。手機、筆電等輸入 100–240V 的充電器，用歐規轉美規的轉接頭就可以；電鍋、電熱水壺、風扇等只標 220V 的電器，在台灣不要硬接，建議改買台灣販售的 110V 電器，或詢問雇主、房東、專業人員。本站內容只是選購方向整理，不是電工或安規建議；電器使用上有疑問時，請以電器銘牌與說明書為準。

## 使用轉接頭的安全注意

- **轉接頭不會改電壓** — 它只改變插頭形狀。台灣是 110V，許多家鄉的電器是 220V 左右；沒有標示 100–240V 的電器，不要因為插得進去就直接使用。
- **先看銘牌，再下單** — 電器或充電器上的「INPUT／輸入」寫的是它可以接受的電壓範圍。包含 110V（或 100–240V）才能接台灣插座。
- **高功率電熱電器不要接** — 電熱水壺、電鍋、熨斗、吹風機、電暖器等耗電大，用小型轉接頭容易過熱；請改用台灣規格的電器。
- **不要疊接或串接過多** — 避免把多個轉接頭、延長線疊在一起使用，插座與線材承受的電流可能超過負荷。
- **插得太鬆就換** — 插頭與轉接頭接觸不緊、搖晃或鬆動，會發熱甚至產生火花；換尺寸合適的款式。
- **發燙、焦味、變色就停用** — 使用中如果摸起來燙手、聞到焦味、外殼變色或變形，立刻拔掉並停止使用。
- **離開時拔掉，勿放在潮濕處** — 不用時拔掉，避免在浴室、廚房水槽旁等潮濕地方使用；孩童拿不到的地方存放。

## 選購前的快速檢查清單

- 方向對了嗎？→ 要選「轉進台灣」（歐規轉美規／圓腳轉扁腳），不是出國旅行用的
- 電器電壓看了嗎？→ 銘牌 INPUT 要有 100–240V 或包含 110V；只標 220V／230V 的不要靠轉接頭解決
- 插頭形狀確認了嗎？→ 先看自己電器的插頭是圓腳還是扁腳，圓腳留意粗細（例如 4.0mm 或 4.8mm）
- 功率夠嗎？→ 賣場沒標示額定功率時，高功率電熱電器一律不要接
- 規格選對了嗎？→ 賣場同頁有多個方向與規格，下單前再確認一次
- 用的時候留意？→ 不疊接、插得緊、發燙或焦味就停用

## 常見問題

**轉接頭可以把 220V 變成 110V 嗎？**
不可以。轉接頭只改插頭形狀，不改電壓。電器的銘牌若標示 100–240V，才可以只用轉接頭；只標 220V 或 230V 的電器，在台灣 110V 的插座不要硬接。

**我的手機充電器可以直接用轉接頭嗎？**
多數手機、筆電的充電器銘牌標示 100–240V，插頭形狀不同時，用「轉進台灣」的轉接頭即可；仍請先看自己充電器上的 INPUT 標示確認。

**電鍋、電熱水壺可以用轉接頭嗎？**
這類電器耗電大，若只標示 220V，不能靠轉接頭解決；轉接頭也可能因為電流大而過熱。建議改用台灣販售的 110V 電器。

**越南、菲律賓的扁腳插頭需要轉接頭嗎？**
有些扁腳插頭的形狀與台灣插座相近，可能可以直接插；但電壓與腳型各國、各產品不同，仍要先看電器銘牌上的電壓，插不緊或有鬆動時請不要硬插。

**賣場同一頁有好幾種轉接方向，要怎麼選？**
要選「轉進台灣」的規格，也就是把歐規圓腳轉成美規（台灣）扁腳。下單前再看一次選項名稱，避免選到台灣轉出國的相反方向。

**轉接頭發燙了怎麼辦？**
立刻拔掉並停止使用。可能原因包括電器功率太大、插頭鬆動接觸不良或轉接頭品質問題；不要繼續使用，也不要疊接其他轉接頭或延長線。
