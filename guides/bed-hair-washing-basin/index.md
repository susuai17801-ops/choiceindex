# 臥床長輩怎麼在床上洗頭？洗頭槽怎麼選：充氣式還是硬式（附步驟與兩款推薦）

最後更新：2026年11月27日
選品索引 ChoiceIndex — https://choiceindex.tw/

長輩長期臥床、行動不便，不能到浴室洗頭，可以在床上用洗頭槽（洗頭盆）洗。蝦皮上的洗頭槽大致分兩種：要打氣的充氣式（軟式），和不用打氣的硬式（塑膠）。這篇整理兩種的差別和怎麼選，再依醫院的居家護理衛教整理床上洗頭的步驟，最後兩種各推薦一款。

## 充氣式和硬式，差在哪

醫院的居家護理衛教只寫「洗頭槽」，沒有說哪一種比較好；照顧者的討論裡，兩種都有人推。下表是我們依商品標示與照顧者討論做的整理，不是實測：

|  | 充氣式（軟式） | 硬式（塑膠） |
|---|---|---|
| 形狀 | 像一個圓形或方形的充氣圈，充氣後成形 | 固定形狀的塑膠槽 |
| 頸部 | 比較軟；充氣多少可以調 | 比較硬，頸部可以墊毛巾 |
| 收納 | 放氣後可以摺起來，不占空間 | 形狀固定，要有地方放 |
| 使用前 | 要打氣或吹氣，打不夠可能會塌 | 拿出來就能用 |
| 要留意 | 會不會漏氣；用完要晾乾再收 | 尺寸和床邊空間合不合 |

如果手邊沒有洗頭槽，澎湖醫院的衛教也提到，可以用橡皮中單或防水塑膠布，把兩邊摺成捲軸，墊在頭下代替。

## 怎麼選

- **家裡空間小、不常洗** — 充氣式放氣後好收，比較適合住雇主家、宿舍空間小的照顧者。
- **每次都怕它塌** — 硬式不用打氣、形狀固定；頸部比較硬，可以墊毛巾。
- **排水方式** — 看有沒有附排水管或排水口，水要能流到床邊的水桶；商品沒寫的，先問賣家。
- **尺寸** — 量一下床寬、床邊放水桶的位置；硬式通常比較長（推薦款約 75 公分），床邊要有空間。
- **要不要打氣筒** — 充氣式有些不附打氣筒，要自己吹氣或另外買。

## 床上洗頭的步驟

以下依衛生福利部澎湖醫院居家護理衛教〈床上洗頭〉整理改寫，詳細請以醫護人員的指導為準：

- **1. 準備** — 洗頭槽、接污水的水桶、一桶乾淨的溫水、洗髮精、毛巾、吹風機。床上可以先鋪防水墊（看護墊）。
- **2. 放好洗頭槽** — 把洗頭槽放在長輩頭下，排水的地方接到污水桶。
- **3. 試水溫** — 用手腕或手肘試溫水；長輩意識清楚的話，問他水溫可不可以。
- **4. 打濕、洗頭** — 先把頭髮打濕，洗髮精倒在手掌上再抹到頭髮，用手指指腹搓揉頭皮和頭髮。
- **5. 沖乾淨** — 用水把泡沫沖乾淨。
- **6. 包頭、移走洗頭槽** — 用毛巾把頭髮包起來，再把洗頭槽拿走。
- **7. 擦乾、吹乾** — 用毛巾擦乾，再用吹風機吹乾、梳整齊。

## 注意事項

- 一般讓長輩平躺洗；呼吸不順的人，改成半坐臥（澎湖醫院衛教）。
- 水溫以長輩的感覺為準，不要太熱或太冷，原則上約 40～43℃（澎湖醫院衛教）。
- 用指腹，不要用指甲抓，以免傷到頭皮；床單弄濕要換（澎湖醫院衛教）。
- 頭部受傷或做過頭部手術的人，暫時不要洗頭（澎湖醫院衛教）。
- 身體不舒服、發燒、身上有管路（例如鼻胃管、氣切管）時，先問醫生或護理師可不可以洗、怎麼洗（這是我們的提醒）。
- 天氣冷時先關窗、把東西都準備好再開始，洗完盡快吹乾（這是我們的提醒）。

## 下單前，先確認這些

- 量好床寬和床邊空間，對照洗頭槽的尺寸。
- 確認怎麼排水：充氣款附排水管；硬式款商品頁沒寫，先問賣家。
- 充氣款不附打氣筒，需要的話在規格選加購，或自己準備。
- 充氣款的賣場要求收到後先吹氣測試，用過就不換；收到後先充氣檢查有沒有漏氣再使用。
- 鑑賞期不是試用期，拆封使用後通常不能退；保固與退換貨以賣場頁面為準，下單前截圖存下來。

## 常見問題

**沒有洗頭槽，可以在床上洗頭嗎？**
可以。澎湖醫院的居家護理衛教提到，可以用橡皮中單或防水塑膠布，把兩邊摺成捲軸，墊在頭下代替洗頭槽，下面接污水桶。

**床上洗頭的水溫要多少？**
澎湖醫院的衛教寫，水溫以長輩的感覺為準，原則上約 40～43℃，可以用手腕或手肘先試。長輩意識清楚的話，直接問他熱不熱。

**什麼情況不要在床上洗頭？**
澎湖醫院的衛教寫，頭部受傷或做過頭部手術的人暫時不要洗頭。發燒、身體不舒服或身上有管路時，請先問醫生或護理師。

**充氣洗頭槽要打多飽？**
推薦的充氣款賣家寫充氣到約八分飽，再依長輩的情況增減。打太少可能會塌，水容易溢出來。

**這兩款有訂單低消嗎？**
充氣款的商品頁寫訂單未滿 99 元（不含運費）不出貨；硬式款的商品頁和賣場首頁，我們沒看到訂單低消。最新規定以賣場頁面為準。
